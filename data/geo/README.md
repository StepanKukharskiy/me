# Local IP-to-country data

`user-country.mmdb` is the IPv4/IPv6 user-country database from
[sapics/ip-location-db](https://github.com/sapics/ip-location-db), downloaded
6 October 2026 from its `latest` release. The data is under
[PDDL](https://opendatacommons.org/licenses/pddl/1-0/).

SHA-256: `e6d85765f72589862497f42a67143fdef6d0cd2567c708dd402e05927420f745`

Lookups run locally; no visitor IP is sent to a geolocation service. This is an
approximation of country, not a person's actual location. Refresh this file
periodically from the upstream release and update the recorded date/checksum.
