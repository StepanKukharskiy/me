# Monthly distribution and visibility record

Record one complete calendar month at a time in `distribution-scoreboard.csv`.
The initial October 2026 row is a partial baseline, not a completed month. Only
the one published personal-site experiment has been counted. Blank values mean
unknown; never replace them with zeros without measuring.

Use the same date range when comparing monthly metrics:

- Google Search Console: search impressions, clicks and the number of AI Work
  experiment articles reported indexed. Sitemap discovery and successful live
  fetches do not establish indexing.
- Bing Webmaster Tools: search impressions and clicks, once the account is set up.
- LinkedIn: followers at period end, post impressions and out-of-network share
  where the account provides that breakdown. Record the exact source and any
  missing data in the notes.
- Published work: personal-site experiment articles and their released Skill
  packages. Exclude drafts and planned experiments.
- Relay: Skill download requests, preserving the metric's request-count meaning.
  These do not establish unique downloads, installations or completed executions.
- Chrome Web Store: the available installation/user metric and its reported
  date range. Keep it separate from extension-link clicks.
- External references: new referring domains and relevant independent mentions
  of Stepan's AI work, each backed by a recorded source URL. Architecture coverage
  provides background, but should not be counted as an AI Work mention.

Use the homepage visitor counts as context, not as a substitute for search or
distribution metrics. Current site activity does not classify visitors as organic
search traffic or measure a complete conversion funnel.

## Fixed AI-search queries

Run these exact queries monthly in ChatGPT Search, Claude with web search,
Perplexity and Gemini with web search available. Use a fresh conversation without
additional background about Stepan. Record whether web search actually ran, the
service/model shown, date, exact query and cited URLs in `ai-search-benchmark.csv`.

1. Who is working on AI automation for architecture?
2. Examples of Agent Skills for professional work
3. How to turn work routines into AI Skills?
4. AI automation experts in computational design
5. Excel to PowerPoint AI Skill

Keep separate fields for a name mention and citations to the personal website,
Relay or Medium. A name mention without a source is not a citation. Record other
sources and competitors in the notes. An unavailable service or a response that
didn't search the web is untested, rather than a failed citation result.

These are repeatable observations, not a guaranteed ranking measure. Save a
shareable result URL where available so comparisons can be checked later.

## Publication checklist

For each new experiment: publish the actual test and limits, release its usable
Skill, add it to AI Work and the sitemap, update the text overviews, and choose the
homepage evidence to feature. Include a byline and truthful publication/update
dates. Publish distribution material separately; set any Medium copy's canonical
URL to the personal article. Keep the same name and positioning across profiles.

No account metrics have been collected by these templates and no monthly
automation has been configured.
